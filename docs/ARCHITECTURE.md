# Architecture: Jenni Khoe MUA – Full Serverless System Design

> **Catatan Keputusan Arsitektur (2026-09-11):**
> Sistem dimigrasikan dari arsitektur hybrid (Laravel 11 + MySQL on VPS) menjadi **Full Serverless**:
> - **Runtime & API**: Next.js 15 App Router di Vercel (`src/app/api/*`)
> - **Database & Auth**: Supabase PostgreSQL 17 + Supabase Auth (`ap-southeast-1`)
> - **Storage**: Supabase Storage Buckets
> - **Keuntungan**: Nol biaya server VPS, deployment instan via GitHub Actions/Vercel, performa tinggi, pemantauan realtime langsung di cloud.

## 2. Authentication & Route Protection

1. **Provider**: Supabase Auth
2. **Admin Credential**: `admin@jennikhoe.com` (role: `admin`)
3. **Login Flow**:
   - Client submit email & password di `/login`
   - Next.js Route Handler `src/app/api/login/route.ts` memanggil Supabase Auth (`/auth/v1/token?grant_type=password`)
   - Mendapatkan JWT `access_token`
   - Menyimpan token di cookie terproteksi `admin_token` (`httpOnly: true`, `secure: true`, `sameSite: lax`)
4. **Middleware Protection (`src/middleware.ts`)**:
   - Memeriksa cookie `admin_token` pada seluruh rute `/admin/*`
   - Memvalidasi token langsung ke Supabase Auth endpoint (`/auth/v1/user`)
   - Jika token tidak valid / kosong, redirect otomatis ke `/login`
   - Jika pengguna sudah login dan membuka `/login`, redirect otomatis ke `/admin`

## 3. Booking State Machine

```
inquiry ──[submit form]──> negotiation
negotiation ──[admin approve + kirim penawaran]──> approved
approved ──[klien bayar DP ≥50%]──> down_payment
down_payment ──[pelunasan sisa tagihan]──> paid
paid ──[admin konfirmasi jadwal]──> confirmed ──[sync Google Calendar]
any state ──[pembatalan]──> cancelled
```

**Aturan Transisi:**
- `inquiry → negotiation`: Otomatis saat calon klien submit form "Cek Jadwal" atau AI chatbot lead.
- `negotiation → approved`: Aksi admin melalui Admin Dashboard (`/admin/bookings`).
- `approved → down_payment`: Callback webhook terverifikasi dari payment gateway (Midtrans / Xendit).
- `down_payment → paid`: Callback webhook pembayaran pelunasan.
- `paid → confirmed`: Admin konfirmasi slot makeup + sinkronisasi event ke Google Calendar.

## 4. Payment Gateway Webhook (HMAC SHA256)

### Endpoint
`POST /api/webhooks/payment`

### Mekanisme Verifikasi
```
HMAC_SHA256(rawRequestBody, process.env.PAYMENT_WEBHOOK_SECRET) == request.headers.get("x-callback-signature")
```
- Signature tidak cocok → HTTP 403 Forbidden
- Idempotency check: Memeriksa apakah `transaction_id` sudah ada di tabel `payments`. Jika sudah `settled`, abaikan secara aman.
- Transisi status booking otomatis:
  - `status = down_payment` jika nominal >= 50% `total_amount`
  - `status = paid` jika seluruh tagihan lunas
- Trigger WhatsApp Dispatcher untuk mengirim pesan tanda terima ke nomor klien.

## 5. Google Calendar Integration

- Disinkronkan melalui Google Calendar API via Service Account / OAuth2 di Next.js API route.
- Menggunakan endpoint **FreeBusy** untuk mencegah double-booking pada tanggal dan jam yang sama.
- Event dibuat saat booking berstatus `confirmed`:
  - Judul: `Jenni Khoe MUA - {client_name}`
  - Waktu: Sesuai tabel `schedules`
  - Lokasi: Sesuai venue pada `bookings`
